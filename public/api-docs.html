🚗 Taller 01 - SaaS API

Gestión Inteligente de Inventario con Atributos Dinámicos

Versión 1.0.0 | Base URL: {{ url('/panel') }}

📚 Visión General

Esta API proporciona un sistema completo de gestión de inventario multitenant con soporte para atributos dinámicos. Cada sucursal/cliente puede tener una estructura de datos personalizada sin necesidad de cambios en el código backend.

🔐 Multitenant

Aislamiento automático de datos por sucursal

📝 Atributos Dinámicos

Personaliza campos sin tocar código

✅ Validación Avanzada

Regex, rangos, límites de longitud

🌍 Multiidioma

Traduce atributos a cualquier idioma

🔐 Autenticación

Todos los endpoints requieren autenticación. Usa sesión con Laravel Session.

⚙️ Atributos Dinámicos

GET /panel/mantenimientos/atributos-dinamicos/categoria/{categoriaId}

Obtener atributos dinámicos de una categoría

categoriaId integer *Requerido - ID de la categoría
POST /panel/mantenimientos/atributos-dinamicos

Crear un nuevo atributo dinámico

categoria_id integer *Requerido
attribute_name string *Requerido - ej: "viscosidad", "rin", "color"
data_type string *Requerido - Valores: text, number, date, select, boolean
is_required boolean - ¿Es obligatorio? (default: false)
options array - Para type=select: ["opción1", "opción2"]
min_value / max_value integer - Para type=number
min_length / max_length integer - Para type=text
validation_regex string - Patrón regex para validación
POST /panel/mantenimientos/atributos-dinamicos Content-Type: application/json { "categoria_id": 5, "attribute_name": "viscosidad", "data_type": "select", "is_required": true, "options": ["15W40", "10W40", "5W30", "20W50"], "help_text": "Selecciona según el manual del vehículo", "display_order": 1 }

✨ Mejores Prácticas

Seguridad y Multitenant

  • Aislamiento automático: Todos los queries se filtran automáticamente por sucursal
  • Middleware de validación: Se verifica que el usuario tenga acceso a la sucursal solicitada
  • CSRF Protection: Todo POST/PUT/DELETE requiere token CSRF

Atributos Dinámicos

  • Los atributos se guardan como JSON en la columna `atributos` de repuestos
  • Se validan automáticamente contra el schema definido en `dynamic_attribute_schemas`
  • Soportan: texto, números, fechas, selecciones, booleanos
  • Incluyen validaciones: regex, min/max, longitud, requerido

Paginación

  • Por defecto: 50 resultados por página
  • Parámetro: ?page=2
